# Catatan lisensi aset ikon

 Paket ikon: Kenney Game Icons
 Sumber: https://opengameart.org/content/game-icons
 Lisensi: CC0 1.0 Universal (domain publik - tanpa atribusi, boleh komersial,
 modifikasi, dan distribusi ulang tanpa syarat). `"CC0 1.0"` tertulis pada
 halaman aset Opengameart dan pada laman lisensi Kenney (kenney.nl).

 Evet yang dipakai dari paket ini:
 - arrowLeft.png   (panah kiri)
 - arrowRight.png  (panah kanan)
 - gear.png        (roda gigi / pengaturan)
 - audioOn.png     (speaker menyala)
 - audioOff.png    (speaker mati)
 - forward.png     (play)
 - return.png      (panah putar / reset)
 - locked.png      (gembok)
 - star.png        (bintang)

 Proses saat masuk proyek (semuanya dirender putih agar bisa diwarnai
 lewat `Image.color` sesuai tema):
 - diskala dari sumber 1x (50x50) ke 128x128, saluran RGB dipaksa putih.
 - importer: Sprite (2D and UI), Single, PPU 100, Full Rect, Filter Bilinear,
   Compression None, Mip Map mati.

 hint.png TIDAK ada di paket aslinya; dibuat sendiri (skrip, gaya flat
 Kenney: siluet lempengan penuh + dasar bergerigi) dan dilepas juga sebagai
 CC0 1.0. Kalau nanti versi resmi Kenney muncul, tinggal ganti filenya -
 kode tak perlu diubah karena hanya memakai guid aset yang sama.
